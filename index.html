RentingRadar Importer — Privacy Policy

Chrome Extension

Effective date: October 20, 2026

Overview

RentingRadar is operated by Summit Capital LLC, a Nevada limited liability company ("Summit Capital," "we," "us," or "our"). This policy covers the RentingRadar Importer Chrome extension only. How the RentingRadar app handles your account and property data is described in the main RentingRadar Privacy Policy.

RentingRadar Importer ("the Extension") is a Chrome browser extension that helps users import rental property data from listing websites into the RentingRadar CRM application. We are committed to protecting your privacy. This policy explains what data the Extension accesses, how it is used, and how it is stored.

Data We Access

The Extension accesses website content (HTML text) from rental listing pages only when you explicitly initiate an import by pasting a URL and clicking "Auto Import" in the RentingRadar CRM. The accessed content is limited to the text of the listing page and is used solely to extract property details such as rent, bedrooms, bathrooms, amenities, and other publicly available listing information.

Data We Do NOT Collect

The Extension does not collect, store, or transmit any of the following:

  • Personal information about you, such as your name, email address, or phone number
  • Health, financial, or authentication information
  • Browsing history or web activity
  • Location data
  • Cookies, credentials, or form data
  • Keystroke, mouse, or scroll activity

How Data Is Processed

When you request an import, the Extension fetches the listing page and extracts property data using one or more of these methods:

  • Built-in pattern matching: Extraction that runs entirely within the Extension. No data leaves your browser.
  • RentingRadar AI: While you are signed in to RentingRadar, the listing text is sent through RentingRadar's servers (Google Cloud) to Anthropic's Claude API, which returns the property details.
  • Your own Claude API key (optional): If you enter a Claude API key in the Extension, it may send the listing text directly to Anthropic's Claude API using your key.
  • Local AI processing (optional): If you run Ollama on your computer, the Extension may send the listing text to your local Ollama instance (localhost). That communication never leaves your machine.

Anthropic processes the listing text under its privacy policy. Only the content of the listing page you chose is sent, not your browsing history or other pages.

Data Storage

The Extension does not keep the listing data. It passes the extracted property details to the RentingRadar app, which saves them to your RentingRadar account (stored with Google Firebase), as described in the RentingRadar Privacy Policy. If you enter a Claude API key, the Extension stores it in Chrome's extension storage.

Third-Party Services

The Extension does not use any analytics, advertising, or tracking services. The only outside services it contacts are RentingRadar, Anthropic (for AI extraction, as described above), and the listing pages you choose to import.

Permissions

The Extension requests the "all URLs" host permission. This is required so the Extension can fetch rental listing pages from any website when you explicitly request an import. The Extension does not access any web pages in the background or without your direct action.

Data Sharing and Selling

We do not sell, transfer, or share any user data with third parties for any purpose. No data is used for advertising, analytics, creditworthiness assessment, or any purpose unrelated to the Extension's core function of importing rental property data.

Children's Privacy

The Extension is not intended for anyone under 18 and does not knowingly collect personal information from anyone under 18.

Changes to This Policy
